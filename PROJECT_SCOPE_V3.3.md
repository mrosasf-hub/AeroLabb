# Alcance — AeroLab Python V3.3

AeroLab Python integra tres rutas de aprendizaje complementarias:

1. **Zona Infantil**: 36 minijuegos para introducir programación mediante actividades visuales.
2. **Ruta Python**: 81 actividades evaluables desde fundamentos hasta proyectos y conceptos intermedios.
3. **CodeWorld 3D**: 12 misiones donde Python modifica un campus futurista mediante variables, decisiones, ciclos, funciones, listas y diccionarios.

V3.3 prioriza una experiencia 3D de entrega: visualmente más rica, responsive, adaptable al hardware y publicable como sitio estático en GitHub Pages.
