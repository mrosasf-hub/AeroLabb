# Alcance de entrega — AeroLab Python V3.4

## Producto
Plataforma web sin login para el aprendizaje progresivo de Python en Aerolab Center.

## Experiencias
1. Zona Infantil: 36 minijuegos distribuidos en mundos progresivos.
2. Ruta Python: 60 lecciones y 21 actividades especiales.
3. CodeWorld 3D: campus explorable con 12 misiones y siete zonas.

## Tecnologías
React 19, Vite, Tailwind CSS, CodeMirror 6, Pyodide, Web Workers, localStorage/IndexedDB, React Three Fiber y Three.js.

## Publicación
Aplicación estática compatible con GitHub Pages mediante GitHub Actions.

## Dispositivos
Laptop, tablet y celular. CodeWorld ajusta calidad gráfica, cámara, controles y distribución de interfaz según el dispositivo.
