## Responsive y rendimiento

- El perfil de calidad ligera ya no se etiqueta como “Rendimiento móvil” cuando el equipo de escritorio tiene pocos recursos; se muestra como “Calidad ligera”.
- Detección de calidad reajustada para que un laptop de pantalla amplia no sea clasificado como móvil por tener 4 núcleos o memoria limitada.
- La calidad ligera conserva nubes, jardineras y algunos elementos de vida, reduciendo densidad en lugar de vaciar el escenario.
- Ajustes de altura con `100dvh` y áreas seguras para navegadores móviles.
- `powerPreference` de WebGL cambia a `low-power` en el perfil ligero.
- Se mantienen carga diferida, React Three Fiber, Three.js y compatibilidad estática con GitHub Pages.
