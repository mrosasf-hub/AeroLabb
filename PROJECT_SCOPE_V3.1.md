# Alcance V3.1 — CodeWorld 3D

AeroLab Python conserva las dos rutas existentes y añade una tercera experiencia:

1. **Zona Infantil** — 36 minijuegos visuales.
2. **Ruta Python** — 60 misiones + 21 actividades especiales.
3. **CodeWorld 3D** — 12 misiones de aplicación dentro de un campus explorable.

## Meta de CodeWorld

Aplicar conceptos de Python en un entorno tridimensional donde el código produzca consecuencias visibles. La experiencia no sustituye el curso: funciona como laboratorio de aplicación y motivación.

## Regla de diseño

El jugador explora manualmente. El código controla sistemas del mundo: puertas, energía, plantas, drones, datos, torre y núcleo.

## Final

Al completar la misión 12, el campus queda restaurado y se muestra el mensaje:

**“Has programado un mundo.”**
