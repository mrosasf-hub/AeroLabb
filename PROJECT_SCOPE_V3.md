# Alcance funcional — AeroLab Python V3.0

## Ruta Python
- 60 misiones principales.
- 21 actividades especiales.
- Explorador, Creador y Developer.
- Editor CodeMirror 6.
- Ejecución con Pyodide en Web Worker.
- Validación flexible por comportamiento/conceptos.
- Pistas progresivas, historial de intentos, explicación de línea y paso a paso.
- Laboratorio y proyectos locales.
- Progreso, XP, estrellas, logros y revisiones de vuelo.

## Zona Infantil
- 4 mundos.
- 36 minijuegos.
- 4 Jefes.
- Selección, predicción, completar, ordenar, depuración visual, rutas y desafíos combinados.
- Narración de instrucciones con Web Speech API cuando el navegador la soporte.
- Progreso infantil independiente.
- Salto final hacia Explorador.

## Dispositivos
- Móvil: 320–760 px.
- Tablet: 761–1100 px.
- Laptop: 1101–1360 px.
- Escritorio: 1361 px o más.

## Persistencia
Sin login. Se utiliza almacenamiento local del navegador (localStorage / IndexedDB según el módulo).
